해충 클레임 관리자 행동강령 및 보상 기준

무전(메이트 더블링)으로 해충 발생을 들은 순간부터 아래 순서로 신속하게 대응하고, 1차 응대 직후에는 CCTV로 마무리합니다.

v2 · 무전 더블링 · 1차 응대 직후 CCTV 확인 추가
1. 기본 행동원칙
  • 1무전(메이트 더블링)으로 해충 발생을 들으면 관리자가 즉시 현장으로 이동해 대응하고, 홀 직원 전원이 해당 위치 주변을 확인하도록 지시합니다.
  • 2해충은 발견 즉시 제거·처리하고, 음식 및 주변 시설의 오염 여부를 확인합니다.
  • 3고객에게는 먼저 사과하고 불편사항을 확인합니다.
  • 4원인을 확인하기 전까지 외부 유입, 음식과 무관 등 원인을 임의로 단정하지 않습니다.
  • 5고객 퇴점까지 집중케어 할 수 있도록 한다.
  • 6고객 상태에 이상이 있거나 음식 혼입·섭취가 의심되는 경우 즉시 본사 핫라인에 보고합니다.
  • 71차 응대 직후 CCTV를 확인해 놓친 고객이 없도록 하고, 발생 위치·날짜를 기록해 재발을 방지합니다.
2. 상황별 관리자 행동강령
★
현장 도착 첫 인사 (모든 상황 공통)
고객이 "똑같은 말을 또 하게" 만들지 않는다
DO
  • 더블링을 들은 후 30초 이내 해당 위치로 이동
  • 명함 제시 또는 지점 책임자임을 밝혀 신뢰감 형성
DON'T
  • "무슨 일이신가요?" 다시 묻기 — 더블링으로 들은 내용으로 바로 사과에 들어간다

"고객님, 안녕하십니까. 오늘 매장 책임자를 맡고 있는 지점장 OOO입니다. 저희 직원을 통해 식사 중 해충 발생으로 큰 불편을 겪으셨다는 이야기를 전달받았습니다. 소중한 식사 시간에 이런 불쾌감을 드려 매장 책임자로서 고개 숙여 사과드립니다."

①
매장 내 이동 해충
바닥·벽·통로 등
관리자 즉시 조치고객 응대 후 즉시 해충 제거 → 주변 확인
보상기준식사비 전액 환불

"고객님, 매장 이용 중 불편한 모습을 보시게 해 정말 죄송합니다. 바로 확인하고 조치하겠습니다."

②
샐러드바·음식 주변 발견
관리자 즉시 조치해당 메뉴 즉시 교체 → 주변 음식·집기 확인 → 필요 시 함께 교체
보상기준식사비 전액 환불

"고객님, 음식 이용 중 이런 모습을 보시게 해 정말 죄송합니다. 해당 음식은 바로 교체하고 주변까지 확인하여 조치하겠습니다."

③
음식에 해충 혼입
관리자 즉시 조치해당 음식 즉시 격리·폐기 → 동일 메뉴 및 주변 음식 확인 → 핫라인 보고
보상기준식사비 전액 환불 + 추가 보상 검토 (상황에 따라 보험 접수)

"고객님, 음식에서 이런 문제가 확인되어 정말 죄송합니다. 우선 해당 음식은 바로 조치하고, 불편을 드린 만큼 식사비는 환불해 드리겠습니다."

④
섭취 또는 신체 이상 주장
관리자 즉시 조치고객 상태 확인 → 필요 시 진료 안내 → 즉시 핫라인 보고
보상기준식사비 전액 환불 + 추가 보상 검토 (상황에 따라 보험 접수)

"고객님, 음식에서 이런 문제가 확인되어 정말 죄송합니다. 많이 놀라셨을 것 같습니다. 현재 불편하시거나 몸에 이상은 없으신가요? 병원 같이 동행하겠습니다."

3. 1차 응대 직후 CCTV 확인⚠ CRITICAL POINT
🚨
확인 시점 — 1차 응대 마무리 "바로 직후"
고객 1차 응대가 끝나면 미루지 말고 바로 CCTV를 확인합니다. 직후에 봐야 아직 매장에 계신 고객을 바로 핸들링할 수 있습니다.
①
놓치는 고객이 없도록
해충 발생 시간 앞뒤로 주변 테이블 확인
CCTV 확인 포인트
  • 주변 테이블 고객 중 해충을 보거나 놀라는 반응을 보인 고객
  • 갑자기 식사를 멈추거나 자리를 옮긴 고객
  • 직원에게 말하지 않고 조용히 퇴점한 고객
확인 후 조치
  • 매장에 계신 경우 — 관리자가 직접 찾아가 사과, 보상은 2번 상황별 기준과 동일하게 적용
  • 이미 퇴점한 경우 — 우선 테이블 번호·시간을 기록하고, 예약 고객이라면 예약자 번호 등 추가 기록 확보

"고객님, 조금 전 매장 내 일로 식사 중 불편하시진 않으셨을까 해서 찾아뵈었습니다. 놀라셨다면 정말 죄송합니다. 혹시 불편하신 점이 있으시면 편하게 말씀해 주세요."

②
재발 방지
해충이 어디서 나왔는지 확인
CCTV 확인 포인트
  • 해충이 처음 보인 위치와 이동 방향
  • 출현 추정 경로 — 천장, 벽 틈, 배수구, 출입문, 식자재 반입 동선 등
확인 후 조치
  • 매장별로 발생 위치·날짜를 기록
  • 기록을 바탕으로 방역업체와 소통
  • 자주 나오는 곳은 방역을 더 집중 관리
  • 위안준 핫라인에 필수 공유
4. 관리자 금지사항
  • ✕해충 방치 금지
    발견 즉시 제거·처리하고, 1차 응대자가 처리하지 못하면 관리자가 즉시 조치합니다.
  • ✕원인 추정 금지
    "외부에서 들어온 것 같다", "음식에는 들어가지 않았다", "방역 때문에 나온 것 같다" 등의 발언 금지
  • ✕보상 축소를 위한 협의 금지
    고객이 느끼는 불편 정도를 고려하여 기본 보상 기준에 따라 안내하고, 임의로 보상을 최소화(일행 중 일부 환불 등)하지 않습니다.
  • ✕현금보상 등 임의 약속 금지
    치료비·현금 등 추가 보상이 필요한 경우 핫라인에 즉시 보고합니다.
  • ✕고객과 논쟁 금지
    사실관계 확인 전 고객의 주장을 반박하거나 책임 소재를 따지지 않습니다.
  • ✕CCTV 확인 생략 금지
    1차 응대가 조용히 마무리되었더라도 직후에 반드시 확인합니다. 미루면 놓친 고객이 이미 퇴점해 핸들링이 어려워집니다.
5. 고객 응대 기본 순서
사과→ 고객 상태 확인→ 현장 조치→ 보상 안내→ 재발 방지 안내→ CCTV 확인

"고객님, 매장 이용 중 불편한 모습을 보시게 해 정말 죄송합니다. 우선 고객님께 불편한 점이 없으신지 확인하고, 해당 부분은 바로 조치하겠습니다. (가이드라인에 맞는 보상안 안내). 또한 동일한 일이 발생하지 않도록 매장도 즉시 점검하겠습니다."
